🚀 Как запустить

  1. Установите Java 25 или новее. Проверить: откройте CMD и введите java -version
  2. Скачайте TerrariaMini.jar (кнопка выше)
  3. Положите файл в любую папку, например C:\Games\TerrariaMini\
  4. Двойной клик по TerrariaMini.jar — игра запустится
  5. Если двойной клик не работает, откройте CMD в папке и введите: java -jar TerrariaMini.jar
💡 Совет: при первом запуске рядом с JAR появятся папки saves/, datapacks/, mods/ — это ваши сохранения и настройки.

🎮 Управление

A / D — движение
Space — прыжок
ЛКМ — копать / атаковать
ПКМ — ставить / открыть / есть
E — инвентарь + крафт
T — чат
C — палитра блоков (креатив)
F11 — полный экран
1–9 — выбор слота

🌐 Мультиплеер

Играть по локальной сети просто:

  1. Один игрок в меню выбирает «Мультиплеер» → «Создать сервер»
  2. Другие игроки вводят IP хоста и нажимают «Подключиться»
  3. Порт по умолчанию: 25565

Для игры через интернет нужен проброс порта или VPN (Radmin VPN, Hamachi, ZeroTier).
